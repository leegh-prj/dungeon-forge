# 프로토타입용 아트 크롭 에셋

이 리소스는 프로젝트의 승인된 AI 생성 아트 시트에서 시각 영역을 잘라 사용한 **임시 시연 에셋**입니다.
투명 배경, 애니메이션 프레임, 단독 아이콘 파츠가 아니며 일부 배경/테두리가 포함될 수 있습니다.

- hero / hero_guard: 주인공 콘셉트 시트
- smith, slime, magma: 캐릭터 아트북
- dungeon, forge: 환경/UI 시트
- weapons / armors / shields / rings: 장비 아이콘 시트

다음 제작 단계: 분리형 투명 스프라이트, 일관된 각도/프레임, 실제 장비 슬롯별 아이콘으로 교체.
