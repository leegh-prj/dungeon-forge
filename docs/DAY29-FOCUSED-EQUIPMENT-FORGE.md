# Day 29 — 한 화면 중심의 대장간·장비 UI

Date: 2026-10-15
Production: https://dungeon-forge-gilt.vercel.app/

## 핵심 UI 원칙
- 전투는 가능하면 한 화면에서 완결. 보상·제작 등 부가 정보는 하위 탭에서 제공.
- 장비·대장간은 첫 화면에 핵심 행동을 노출하고, 목록·세부 정보는 별도의 서브 화면 또는 접이식 패널로 이동.
- 단말 크기에 맞춘 반응형 너비와 제한된 내부 스크롤은 유지. 콘텐츠 유실 방지와 터치 영역 확보를 우선.
- 결제·광고 연동 추가 없이 게임 경험 품질 개선.

## Day 29 구현
1. 장비 화면을 **착용 / 가방 / 창고** 3개 서브 탭으로 분리.
2. '착용' 화면에는 캐릭터 외형, 장착 아이템, 능력치, 세트/업적/프리셋과 '가방 관리' 바로가기만 보임.
3. '가방' 화면에는 부위 필터, 검색·정렬과 내부 스크롤 장비 목록만 표시. 장착, 상세, 잠금, 창고 보관 동작은 기존 로직 유지.
4. '창고' 화면에는 보관된 아이템 목록과 가방 복귀 동작을 표시. 저장 공간 설정은 창고 페이지에서 접이식으로 접근.
5. 대장간 일반 제작 시 4개 아이템 카드 대신 **현재 선택한 부위 카드 한 개**만 보여줌.
6. 첫 제작 C/B 시각 프리뷰는 실제 스타터 등급을 기준으로 표시하고, 신규 튜토리얼의 B 확정 제작도 반영. 레전드 확률을 확정 장비처럼 보이는 미리보기는 제거.
7. 확률 안내, 연속 제작(5회/목표 등급 20회), 지역 속성 제작을 개별 접이식 영역에 통합. 기본 제작 버튼과 집중 옵션이 우선 노출됨.
8. 착용/가방/창고 전환 시 게임 내부 스크롤을 상단으로 초기화. 기존 저장 키 `dungeon-forge-ui-v2` 변경 없음.

## 검증
13/13 JS/DOM 회귀 점검 통과:
- 5개 주 메뉴 화면
- 기본 착용화면과 가방/창고 페이지 분리
- 창고↔가방 이동
- 제작 카드 하나 및 접이식 고급 제작 영역
- 강화/분해 탭 보존
- 신규 튜토리얼 흐름
- 반응형/안전 영역 CSS 유지
- 기존 L+20 장비·스테이지·자동 전투 설정 보존
