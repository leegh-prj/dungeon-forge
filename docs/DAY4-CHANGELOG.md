# Day 4 — 판타지 UI 스킨 1차 반영

일자: 2026-10-13  
대상: `index.html` (GitHub Pages 웹 프로토타입)  
디자인 기준: [UI_STYLE_GUIDE.md](UI_STYLE_GUIDE.md)

## 구현 내용
- 석재·금속 패널, 앰버/골드 강조 버튼, 푸른 던전 배경
- 보스 경고창, HP 바, 장비 카드, 희귀도 텍스트, 하단 탭 공통 스킨
- 대장간 화덕·모루·불꽃 분위기 배너 추가 (CSS 기반 임시 연출)
- 모바일 370px 이하 폭 대응 CSS
- 기존 Day 3 탭 클릭 안정화 로직 유지

## 아직 하지 않은 내용
- 영웅·몬스터·NPC·아이템 **개별 스프라이트 실물 교체**
- 생성 시안의 글자/합성 이미지 직접 사용 (아트 참조용으로만 사용)
- Godot 씬 UI 재작업
- 모바일 브라우저 수동 QA, Android/iOS 네이티브 빌드

## 확인할 사항
1. 브라우저에서 네 탭이 정상적으로 작동하는가?
2. 좁은 스마트폰 화면에서 재화/버튼이 잘리지 않는가?
3. 대장간에서 균형·공격·방어 제작이 작동하는가?
4. 보스 공격 예고와 방어 버튼이 정상 작동하는가?

## 다음 개발 순서
1. 캐릭터/슬라임/대장간 장인/무기/방패 스프라이트 에셋 세트 제작
2. 스프라이트 적용 및 CSS 임시 아이콘 제거
3. 제작 연출: 금속 타격 → 불꽃 → 등급 공개
4. Godot 스킨 이식, 브라우저 및 실제 기기 검증
