# Day 9 — 대장간 전체 기능 연동

## 구현 (2026-10-14)
- **제작:** 기존 확률형 장비 제작 유지.
- **강화:** 장비 하나를 선택하고 골드·광석을 사용하여 +1 강화. 최대 +10. 능력치 증가와 레벨 로컬 저장.
- **분해:** 장비 하나를 소모하고 등급·강화 수준에 따른 광석 및 일부 마력 결정 회수.
- **합성:** 같은 부위·등급의 미장착 장비 3개와 재화를 소모해 다음 등급의 새 장비 획득 (SS 제외).
- **승급:** 같은 부위·등급의 미장착 장비 2개와 강화된 비용으로 다음 등급 장비 획득 (SS 제외).
- 장착 중인 아이템은 분해·합성·승급 불가. 삭제 후 장착 인덱스를 재조정하여 다른 장비 장착 유지.
- 기존 localStorage 키 유지: `dungeon-forge-ui-v2`. 기존 저장 기록 초기화하지 않음.
- 세부 비용은 UI에서 자원별 확인. 비용 부족·장비 부족 시 실행 버튼 비활성화.
- 강제 새로고침 후에도 인벤토리와 재화는 localStorage에 보존.

## 테스트
자바스크립트 구문 검사 및 모의 DOM 기반 로직 테스트: 합성 3→1, 강화 능력치·레벨 증가, 분해 수량 감소, 승급 2→1 통과. 실제 모바일 브라우저 조작과 사용자 데이터 마이그레이션에 대한 장기 검증은 후속 과제.

- 강화 연속 처리 및 실패 확률 밸런스
- 도감·퀘스트와 대장간 작업 연동
- 전투 수치·그래픽 밸런스
