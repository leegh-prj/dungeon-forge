# 던전 대장간 개발 현황 종합 및 Day 24 업데이트

작성일: 2026-10-15
프로젝트: leegh-prj/dungeon-forge
프로덕션: https://dungeon-forge-gilt.vercel.app/

## 1. 게임 개요
- 제작 약 60%, 전투 약 40%의 싱글플레이 브라우저 RPG.
- 메인 화면: 던전, 대장간, 장비, 도감, 상점.
- 저장 방식: 브라우저 localStorage (`dungeon-forge-ui-v2`); 동일 기기/브라우저에 한정된 로컬 저장.

## 2. 누적 개발 현황 (Day 1–23)
1. 장비 수집: 무기/갑옷/방패/반지, C/B/A/S/SS/SSS/L 일곱 등급.
2. 일반/일괄/목표 등급 제작(한 번에 최대 20회), 지역 속성 제작.
3. 강화 +0~+20: 로그 기반 확률 급감, 강화 실패 누적 보정, 실패 시 재료 소모/장비 보존.
4. 같은 부위·등급 아이템 합성/승급, 등급별 획득 씬/사운드/UI와 고등급 벡터 장비 아트.
5. 장비 도감, 옵션 재설정, 장비 비교, 세트 효과, 정렬/검색.
6. 가방 기본 120개·창고 기본 200개, 창고 이동·확장, 신규 저등급 장비의 선택적 자동 분해(S 이상 보호).
7. 던전 자동/수동 전투, 스테이지 순환과 보스 패턴, 지역별 세트 공명 및 전투 보정.
8. 일일 던전 미션, 7일 출석, 오프라인 보상(최대 8시간), 월간 무료 장인 여정.
9. 별빛 게임 내 재화 상점과 확장 편의 보상. 현금 결제·광고 SDK는 **미연동**. 미출시 유료 상품은 사용 불가로 표시.
10. 모바일/일반 UX: 접이식 설정 패널, 일일 보상 일괄 수령, 장비 검색 결과, 3개 프리셋.

## 3. Day 24 구현
- **지역 제작 목표**: 던전 화면에서 현재 지역의 재료를 4개까지 얼마나 모았는지 게이지로 보여주고, 부족량/제작 가능 여부를 명확히 안내.
- **대장간 직행**: 지역 제작 목표 카드에서 대장간 제작 탭으로 이동하면서 현재 지역 속성 제작 재료 선택.
- **보스 공략 안내**: 다음 보스 패턴의 이름과 방어·회복·공격 대응 팁을 보스 전투 중 표시.
- **강화 성공 확률 시각화**: 수치뿐 아니라 접근성 속성을 가진 성공 확률 게이지 표시. 기존 확률 및 보정 공식은 변경하지 않음.
- 기존 저장 키, 아이템과 재화, 전투 계산식 및 과금 준비 상태 유지.

## 4. Day 24 검증
8/8 mocked DOM/JS checks pass:
- 다섯 메인 메뉴 렌더링
- 던전 지역 제작 카드 표시
- 재료 3/4 부족 상황, 4/4 준비 상황
- 대장간 제작 직행/지역 선택
- 보스 패턴 힌트
- +10 강화 게이지와 실 확률 수치 매칭
- +20 강화 최대치 차단

## 5. 보완 우선순위
1. 실제 모바일 브라우저 터치·스크롤·화면 전환 자동화 테스트.
2. 신규 유저 첫 5분 튜토리얼 및 전투/제작 경험 흐름 보정.
3. 보스 패턴 다양화와 던전 난도/보상 밸런스.
4. 장비 도감·합성·속성 제작의 반복 플레이 장기 목표 확장.
5. 수익화는 기능·UI 품질 안정화 후 실 광고/결제 SDK, 사용자 동의·구매 검증·복원 포함 별도 연동.

## 주의
Mock DOM 검증은 코드의 주요 흐름 테스트이며, 실제 모바일 실기기 QA를 대체하지 않음.
