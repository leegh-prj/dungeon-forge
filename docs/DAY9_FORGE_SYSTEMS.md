# Day 9 — 대장간 실제 기능 구현

## 배포
- 웹 플레이: https://dungeon-forge-gilt.vercel.app/
- HTML: `index.html`
- 제작·강화·분해·승급·합성 엔진: `forge.js`
- 원본 Day 8 저장 데이터 키 `dungeon-forge-ui-v2` 유지. 기존 재화/장비 보존.

## 5가지 작업
| 탭 | 규칙 |
| --- | --- |
| 제작 | 기존 랜덤 등급 및 효과 제작, 인벤토리/장착/도감 반영 |
| 강화 | 대상 장비 +1~+10, 광석 및 골드 차감. 확정 성공. 능력치 상승 |
| 분해 | 미장착 장비 1개 소모, 광석/결정 반환 |
| 승급 | +3 이상인 장비를 다음 등급으로 올림 (SS 제외). 결정과 골드 사용, 강화 단계는 0으로 초기화 |
| 합성 | 같은 등급의 미장착 장비 2개 소모, 한 단계 상위 등급 무작위 장비 1개 생성 (SS 제외). 결정 소모 |

## 안정성
- 장착 중인 장비는 분해·합성 불가
- 인벤토리 삭제 후 장착 인덱스 재정렬
- 강화·승급 시 캐릭터 전투 스탯 및 최대 HP 갱신
- 거래 후 자동 저장 및 탭 갱신
- 장비 화면의 전체/무기/갑옷/방패/반지 필터 동작
- 기존 게임 데이터에 `level`이 없어도 기본 0으로 취급

## 테스트
연결된 GitHub의 `forge.js`를 로드하여 별도 격리된 JS 환경에서 다음 시나리오 7개를 검사: 3회 연속 강화, 능력치 상승, +3 이후 승급, 장착 아이템 분해 차단, 분해 환급, 인덱스 유지, 두 장비 합성. 7개 통과.

## 후속 개선
- 분해·합성 시 재확인 모달 및 사용 전 상세 내역
- 자동 강화/다중 분해 기능
- 제작/합성 결과 전용 애니메이션
- 모바일 실기기에서 버튼·스크롤·재화 잔액 UX 검사
