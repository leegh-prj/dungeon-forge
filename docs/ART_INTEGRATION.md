# 그래픽 적용 가이드 — Day 5

## 적용 순서
1. [UI 스타일 가이드](UI_STYLE_GUIDE.md)와 [확장 설계](EXPANSION_ARCHITECTURE.md) 기준 준수
2. ChatGPT에서 제공한 `dungeon-forge-art-assets.zip`을 압축 해제
3. 저장소 최상위에 `assets/art/*.webp` 경로 유지
4. `git add assets/art` → `git commit -m "Add fantasy game art assets"` → `git push origin main`
5. GitHub Pages에서 게임 확인

## 현재 웹 코드 반영
- 던전: 영웅/일반 슬라임/보스 아트 및 던전 배경
- 대장간: 장인·화덕 장면 이미지
- 장비: 방어 포즈 영웅 이미지
- 도감: 무기·방패 컬렉션 그림
- 이미지 미존재 시 기본 UI로 폴백하여 게임 이용 가능

## 임시 에셋의 한계
현재 이미지는 승인된 AI 아트북에서 시각 영역을 추출한 **크롭 임시 에셋**입니다. 투명 스프라이트, 개별 장비 슬롯용 이미지, 행동별 애니메이션 원본은 아닙니다. 텍스트/복합 배경이 일부 포함될 수 있어 2차 고도화 때 교체가 필요합니다.

## 그래픽 개발 수용 기준
- 모바일 360px 너비에서 글자/리소스 영역이 잘리지 않는다
- 이미지가 없는 상태에서도 기본 전투와 제작 탭이 작동한다
- 그래픽 표시가 새로운 플레이/저장 오류를 만들지 않는다
- 투명 스프라이트 및 개별 슬롯 아이콘이 준비되면 기존 크롭에 우선해 교체한다
