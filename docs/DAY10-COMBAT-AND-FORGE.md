# Day 10 — 자동/수동 전투 + 대장간 고도화

배포 기준: 2026-10-14

## 전투 조작
- **자동 모드**: 기본 공격, 강타(7초 재사용), 보스 공격 직전 방어(5.5초 재사용)를 자동 실행. 기본 모드는 자동.
- **수동 모드**: 공격(빠른 기본 공격), 강타, 방어를 직접 조작. 적은 시간마다 공격하므로 방어 예고에 맞춰 사용.
- 적 공격 카운트다운, 강공격 경고, 공격·피격·방어 CSS 모션과 데미지 표시.
- 모드 상태는 기존 localStorage 저장키(`dungeon-forge-ui-v2`)에 저장. 기존 세이브 초기화 없음.
- 장비 공격력·방어력·최대 체력 수치 노출. 무기 화상 추가 피해, 갑옷 견고함 피해 감소, 방패 보호막 피해 감소, 반지 반격 피해, 냉기 지연/흡혈 등 효과 반영.

## 대장간 및 장비
- **잠금**: 장비에서 개별 잠금/해제. 잠긴 장비는 분해·합성·승급 재료 목록에서 제외.
- **일괄 제작**: 선택 부위 5회 연속 제작(부족한 자원이 있으면 가능한 횟수까지).
- **일괄 분해**: 선택한 등급 이하 최대 50개, 장착·잠금 아이템은 제외.
- **결과 연출**: 강화·합성·승급·일괄 제작·분해 결과 팝업. 강화 전후 능력치 비교.
- **전투 장착 보호**: 제작 시 장착 중인 장비보다 강한 장비에 한해서 자동 교체. 낮은 등급 제작으로 고등급 장비가 교체되는 문제 방지.
- 강화·합성·승급 기능은 Day 9에서 구현했으며 이번 버전에서 관련 잠금/결과 연출을 연결.

## 검증
- JavaScript 파서 검증 통과.
- 모의 DOM 및 localStorage 환경에서 다음 로직 테스트 통과:
  1. 수동 공격 적 HP 감소
  2. 자동 모드에서 수동 공격 입력 무시
  3. 잠긴 장비 재료 목록 제외
  4. 일괄 분해 시 잠긴 장비 보존 및 재화 회수
  5. 5회 제작 시 아이템 5개 생성
  6. 기존 강한 장비 자동 교체 방지
  7. 장착 아이템 변경에 따른 실제 전투 공격력 갱신
