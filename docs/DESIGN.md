# MVP 설계 결정 2026-10-12

- Crafting : Combat = 60 : 40.
- 제작: 단검, 철갑옷, 수호 방패, 마력 반지. 각 옵션 랜덤 추첨.
- 방어력: 기본 3 + 장비 방어력.
- 받는 피해 = 원래 피해 × 100 / (100 + 방어력).
- 방어 스킬: 2.2초간 피해 75% 감소, 재사용 8초.
- 보호막 옵션: 피해 15% 추가 감소.
- 실패: 골드·장비를 잃지 않음.
- 탐험 오프라인 골드·광석 수급: 최대 8시간 인정.
- 향후 작업: 시각 아트, 선택지 기반 사건, 장비 계열 효과 개선, 밸런스 및 기기 테스트.
