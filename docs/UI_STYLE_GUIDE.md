# 던전 대장간 — 아트 & UI 스타일 가이드 v1.0

> 상태: **승인됨 / 프로젝트 공통 기준** · 2026-10-13
> 범위: 웹 프로토타입, Godot, 향후 그래픽 에셋, 마케팅 시안에 동일 적용

## 1. 게임 정체성
- 가칭: **던전 대장간 (Dungeon Forge)**
- 장르: 판타지 방치형 RPG × 랜덤 장비 제작 × 타이밍 방어
- 기획 비중: **제작 60% / 전투 40%**
- 한 줄 콘셉트: **더 강한 장비가, 더 멀리 간다.**
- 키워드: **귀여운 치비 캐릭터 / 묵직한 판타지 UI / 따뜻한 불꽃 / 차가운 던전 / 수집 욕구 / 제작의 쾌감**
- 목표 인상: 소규모 게임이라도 정돈된 상용 모바일 판타지 RPG처럼 느껴질 것

## 2. 고정 아트 디렉션
- 캐릭터: 머리가 크고 실루엣이 명확한 **2D 치비 카툰**, 귀엽지만 장난스럽지 않음.
- 환경: 석재, 쇠, 나무, 가죽, 양피지, 수정, 불꽃을 바탕으로 한 판타지.
- 빛: 대장간의 **앰버·골드 난색 조명**과 던전의 **코발트·청록 냉색 조명** 대조.
- UI: 금속 테두리, 얕은 입체 그림자, 작은 장식, 뚜렷한 클릭 상태. 무조건 과장된 장식보다 정보 가독성 우선.
- 희귀 아이템: 외곽광/입자/등급별 프레임을 사용하되 색상만으로 희귀도를 표현하지 않음.
- 절대 금지: 주요 아트에 운영체제 이모지 그대로 사용, 화면마다 다른 세계관, 밝은 플랫 대시보드 느낌, 읽기 어려운 과장 폰트.

## 4. 공통 컴포넌트
- 상단 리소스 바: 골드/광석/마력 결정 항상 동일 순서와 단위.
- 제목: 금색 타이틀 + 간결한 섹션 부제.
- 판넬: 어두운 석재 배경 + 1px 금속 테두리 + 안쪽 명암 + 둥근 모서리.
- 주 CTA: 금색/호박색 그라디언트 **제작하기 / 강타**.
- 방어 CTA: 빛나는 블루 그라디언트 **방어**.
- 보조 CTA: 회청 금속 패널. 비활성은 명도·광택을 낮춤.
- 내비게이션: 던전 / 대장간 / 장비 / 도감, 선택 탭에 금색 포인트.
- 최소 터치 영역: 44×44 CSS px, 모바일 세이프에어리어 고려.
- 주요 본문 13~16px 이상, 장식은 의미 있는 정보 가독성을 해치지 않도록.

## 5. 화면별 규칙

### 던전
- 푸른 지하 유적/동굴, 거리감 있는 배경, 주인공과 적의 선명한 실루엣.
- 체력바·보스 예고·강타/방어 버튼을 1순위로 배치.
- 보스 강공격은 붉은 경고, 방어 성공은 청색 섬광/피해 감소 피드백.

### 대장간
- 따뜻한 화덕, 모루, 불티, 장인의 작업 공간.
- 제작 재료 → 제작 부위 → 제작 집중(균형/공격/방어) → 제작 결과 순서.
- 제작 시 스파크·해머 타격·등급 공개 단계적 연출을 목표로 함.
- **방어구(갑옷·방패)**는 무기와 동등한 주요 제작 카테고리로 노출.

### 장비
- 치비 영웅을 중심으로 무기·갑옷·방패·반지 장착 위치 표시.
- 공격·방어·HP를 고르게 강조. 상승/하락 수치를 명확하게 구분.
- 장착된 장비와 보유 장비의 프레임 상태를 달리할 것.

### 도감
- 양피지/고서의 질감, 미수집은 잠긴 실루엣.
- 전체 수집률과 분야별 진행률, 발견 시 등록 반응 제공.
- 탭: 장비 → 몬스터 → 지역 순서로 확장 가능.

## 6. 게임 플레이와 아트의 결합
- 무기 특성: 화상(주황), 흡혈(적자색), 번개(청백) 등 고유 이펙트.
- 방어 특성: 보호막(푸른 반구), 반격(검파), 피해 감소(방패 광택).
- 전설 장비: 별도 테두리, 불티/광채, 결과 연출로 가치 표현.
- 재접속 시: 오프라인 보상을 보물상자/보상 패널로 명확히 안내.

## 7. 제작·검수 규칙
- 웹 HTML/CSS와 Godot의 동일한 기능은 **용어, 토큰, 화면 배치**를 최대한 일치시킬 것.
- 최종 생성 이미지의 텍스트를 게임 버튼으로 사용하지 말 것. 실제 글자는 게임 UI로 렌더링.
- 합성 목업 이미지는 **아트 참고용**이며 개별 UI 스프라이트로 직접 크롭해 사용하지 않음.
- 모바일 세로화면 360px 및 390px 너비 테스트, 터치 오류, 대비, 확대 시 글자 잘림 검증.
- 변경 시: 코드 작성 → 정적 검사 → GitHub 커밋 → GitHub Pages → 실제 폰 확인 순서.

## 8. 개발 순서
1. 스타일 토큰과 던전/대장간/장비/도감 공통 UI 스킨.
2. 치비 영웅/몬스터/대장간 NPC/장비 아이콘 등 **일관된 개별 에셋** 제작.
3. 제작 성공·희귀 등급 공개·방어 성공 이펙트.
4. Godot 씬에 동일 디자인 이식.
5. Android/iOS 테스트와 성능 및 자산 크기 최적화.

> 본 문서는 사용자가 승인한 UI 기준의 단일 기준 문서다. 향후 스타일 변경 시 버전 및 변경 이유를 기재한다.
